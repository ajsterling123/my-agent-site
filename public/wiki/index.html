Wiki

这里是个人的文件化 Memory：一个知识点一个 md 文件，写在 content/wiki/，由 scripts/build_wiki.py 构建成 public/wiki/ 下的静态页面；规则本身也是文件，见 content/wiki/README.md。

页面之间的 [[双向链接]] 在构建期解析成站内链接，显示文字默认取目标页的标题；每页底部另有「链接到此页的页面」，由脚本从正文反向查出——引用了谁与被谁引用都落在同一页上，这才是「双向」的本义。链接写向不存在的页面会直接让构建失败，所以这里不存在坏链；清单与反向链接都不手维护，保证与内容永不错位。

内容按「我的原话 / Agent 总结 / 外部来源」三类区分写法，未经确认的推断不入库。第一个词条是 第一次 Agent 实验：讲清目标、约束与验收：给 Agent 交代任务的方法与验收习惯，由同名博客文章提炼而来，只留知识点，不复述全文。
