## 核心认识

> 我发现，和 Agent 协作的关键不是把句子写得很长，而是给出清晰的目标、约束和验收标准。
>
> —— 张易孝原话，出处：本档案博客文章[《我的第一次 Agent 实验》](../posts/hello-agent.html)

## 交代任务的三问

给 Agent 交代任务时依次说明三件事：

1. 用户是谁；
2. 页面应该包含什么；
3. 如何判断完成。

## 验收必须实际执行

给 Agent 的验收标准要落成可执行的检查，本条目的做法：

- 连续运行两次构建脚本，第二次之后 `git status` 干净（幂等的证据）；
- 跑机械校验脚本（如 `python tools/check_site.py`）；
- 起本地 http 服务（`python -m http.server 8080 --directory public`），在浏览器里打开生成页，确认样式加载、导航可跳转；
- 390px 与 320px 宽度下无横向滚动。
